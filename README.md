# Car Service

Одностраничный сайт автотехцентра «Car Service» (Тольятти, Комсомольская ул., 84А, стр. 1).

- Сайт: https://qweldesy.github.io/car-service/
- Карточка-источник: https://yandex.ru/maps/org/car_service/26343350328/
- Референс: https://ru.pinterest.com/pin/1004232416945489329/

## Контент

Услуги, цены, отзывы, фотографии, рейтинг и адрес взяты из карточки организации на Яндекс Картах.
Ничего не придумано: направления сгруппированы из списка «Виды работ» и особенностей карточки,
прайс — 21 позиция из раздела «Товары и услуги».

Факты из карточки:

- рейтинг 4,3, 146 оценок, 54 отзыва;
- график: ежедневно 09:00–19:00;
- направления: базовое сервисное обслуживание, развал-схождение, шиномонтаж и балансировка,
  ремонт подушек безопасности, установка фаркопа, студия тюнинга;
- 92 фотографии в альбоме (на сайте — 12);
- оплата картой, парковка, скидки и акции, частичная доступность.

Прайс в карточке помечен как «Давно не обновлялось» — на сайте это указано, стоимость
рекомендуется уточнять по телефону.

Контакты: +7 (902) 293-88-38 (телефон из задания, Telegram и WhatsApp),
+7 (902) 424-94-88 (телефон, указанный в карточке), VK: vk.ru/car_service163.

## Структура

```
index.html          — разметка, SEO, Schema.org
css/style.css       — дизайн-система и адаптив
js/main.js          — меню, лайтбокс, Motion-анимации
js/motion.js        — Motion 12 (vanilla, локально)
fonts/              — Tektur + Inter, кириллица и латиница
img/                — фото из карточки, оптимизированные в WebP
```

## Локальный запуск

```bash
python3 -m http.server 8124
# http://localhost:8124
```
